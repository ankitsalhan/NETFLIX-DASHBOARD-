# 🎬 Netflix Data Analytics & Interactive Dashboard

This project is a comprehensive analysis of Netflix's content library (Movies and TV Shows), visualized through an interactive **Tableau Dashboard**.

## 📊 Key Highlights & Features
- **Content Distribution:** Visual split between Movies and TV Shows.
- **Geographical Insights:** World map representation of content availability by country.
- **Timeline Analysis:** Growth trends of content added over the years.
- **Audience Categorization:** Breakdown by maturity ratings (TV-MA, TV-14, PG-13, etc.).
- **Genre Classification:** Top performing genres across the platform.

## 🛠️ Tools Used
- **Visualization:** Tableau Public / Desktop
- **Data Source:** Netflix Titles Dataset (CSV)
